# Political Ascent

**Political Ascent** is a hybrid RPG / grand strategy / political simulation
game. You play a single politician navigating legislation, factions,
public opinion, and personal ambition inside a modelled country.

This wiki is the player- and modder-facing knowledge base. Developer
documentation lives under [`docs/`](https://github.com/ScottyVenable/Political-Ascent/tree/development/docs)
in the main repository.
