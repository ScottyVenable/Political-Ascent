# Character

The player character is a single politician with a background, a trait
set, starting skills, and an office (or an ambition to hold one).

## What the system covers

- Character creation: background, traits, starting skills.
- Personal attributes that influence action success (charisma,
  discipline, rhetoric, etc.).
- Relationships with factions, donors, and voters.

## Design notes

- Traits are data-driven; see `src/data/traits.json`.
- Backgrounds are templates that bundle starting traits, skills, and
  relationships.
