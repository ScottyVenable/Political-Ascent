# Reference Images

This folder contains reference images used for ideas, inspiration, and guidance throughout the development of **Political Ascent**.

## Purpose

These images serve as visual references to help shape the look, feel, and design of the game. They are **not** owned assets intended for direct use in the project, but rather collected inspiration to inform creative and technical decisions during development.

## Categories

- **UI / UX** – Interface layouts, menu designs, HUD concepts, button styles, typography, and color schemes that inspire the game's user experience.
- **Visual Design** – Art styles, color palettes, iconography, and general aesthetic direction.
- **Game Design** – Screenshots or mockups from other games that demonstrate mechanics, progression systems, or design patterns worth referencing.
- **World & Theme** – Political imagery, government aesthetics, campaign visuals, and thematic inspiration relevant to the political setting of the game.
- **Miscellaneous** – Any other reference material that may be useful during development brainstorming.

## Guidelines

- Label or organize images clearly so their purpose is easy to understand at a glance.
- If an image has a specific source or context worth noting, add a comment or companion `.txt` file alongside it.
- Do not use reference images as direct game assets without proper licensing or creation of original replacements.
