# Political Ascent — v0.1.0-alpha (development)

This is the first development build aggregating all stacked PRs from
`experimental` since the project bootstrap. It is **not** a stable
release; expect rough edges.

## Highlights

- Full character creation flow with seven core stats, ideology compass,
  trait pickers, and scenario selection.
- Card system with rarity tiers, AP and cooldown enforcement, and
  pack-opening flow.
- Tooltip system (`Term`, `TermText`, ExtendedTooltip) reaches every
  major panel; nested tooltips stack correctly via `TooltipDepthContext`.
- Browseable in-game **Glossary** panel with search and category filters.
- Chronological **Timeline** panel grouping every news headline by month.
- Two-pane **Quests** browser with filter pills, full descriptions,
  prerequisites, and rewards humanised from the underlying `Effect[]`.
- Clickable entity references (`<EntityLink>`) — Timeline headlines
  jump to the relevant panel in one click.
- `Sync-with-Drive` launcher task mirrors the working tree to a Google
  Drive backup folder via robocopy.

## Bug fixes

- Events no longer fire multiple times after being resolved
  (persisted `firedEventIds`, per-event cooldown, idempotent
  `resolveOption`).
- Dashboard KPI tiles are now real buttons with colour-coded values
  (approval gradient, GDP green/red, deficit/unemployment thresholds).

## Known issues

- AI-driven NPC AI is stubbed; legislators vote based on simple
  ideology heuristics.
- The Statesman card's animated background is unreliable in some
  browsers — fix tracked under a future card-physics PR.
- Right-click context menus are not yet implemented.
